# TikTrad

Application Android : récupère le son d'une vidéo TikTok, le transcrit (arabe, darija, hassaniya…) et le traduit en français avec l'API Gemini.

## Installation
Télécharger `TikTrad.apk` depuis la dernière Release et l'installer (autoriser « sources inconnues »).

## Utilisation
1. Créer une clé gratuite sur https://aistudio.google.com/apikey et la coller dans les Réglages de l'app.
2. Dans TikTok : Partager → Copier le lien (puis coller dans l'app), ou Partager → Plus → TikTrad.
3. Alternative : « Enregistrer la vidéo » dans TikTok, puis « Choisir une vidéo » dans TikTrad.
